IMPORTANT FORMULAS
--------------------------------------------------

Conv2D output (valid padding, stride 1):

output = input - filter + 1


Conv2D parameters:

(filter_height × filter_width × input_channels + 1)
× number_of_filters


Dense parameters:

(input_neurons × output_neurons)
+ output_neurons


MaxPooling output:

floor((input - pool_size) / stride) + 1


Flatten:

height × width × channels


"None":

None represents the batch size.
Keras leaves it unspecified because you can give the model
any number of images at once.

For example:

(32, 100, 100, 1)
(64, 100, 100, 1)
(952, 100, 100, 1)

are all valid batch sizes.
